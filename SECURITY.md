# Ασφάλεια / Security

Αν βρεις πρόβλημα ασφαλείας (π.χ. τρόπο να διαβάσει μια ιστοσελίδα τα δεδομένα του Tameio), **μην ανοίξεις δημόσιο issue**. Στείλε το ιδιωτικά από την καρτέλα **Security → Report a vulnerability** του repo.

If you find a security issue (for example, a way for a website to read Tameio's data), **don't open a public issue**. Report it privately from the repo's **Security → Report a vulnerability** tab.
